#   `rule`/`panel` sur toute instance (panneaux de dashboards is_soql=1 + règles de détection is_soql=1)

# Sans ces trois lignes, la branche NOCASE du miroir plume_parity est du code MORT (mutation non détectée).

search source in (80,web)
